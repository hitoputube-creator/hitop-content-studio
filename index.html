템플릿 선택 (모양을 보고 고르세요)

매물 주소가 와동동·운정 일대면 상권 설명이 자동으로 켜집니다. 다른 지역 매물에 운정역 상권 설명을 넣으면 오해를 줄 수 있어 기본은 꺼짐입니다.

이미지 배경 사진 선택 (사진이 없으면 색 배경으로 만들어집니다)

소유주 이름·연락처, 비공개 주소는 사용하지 않습니다. 공개 글과 이미지에는 건물명·호수·번지 없이 "동 단위 위치와 층수"만 들어갑니다. 건물명이나 호수를 직접 적으면 공개되니 주의하세요. 옵션을 바꾸면 글과 이미지가 새로 만들어지며, 직접 고친 글은 사라집니다.

4. 파트별 구성과 이미지

글을 파트(표지 · 매물 정보 · 상권 설명 · 추천 · 상담)로 나누고 파트마다 상호·연락처가 들어간 이미지를 만듭니다. 내용을 고치면 이미지가 바로 바뀌고, 인스타·스레드는 이 이미지를 번호 순서대로 올리면 됩니다.
